Position

Why us and not the next endpoint

Qwen3.8-27B is open. Anyone can serve it, and plenty do. The difference between providers is not the weights — it is what the weights run on.

Tannit's advantage sits in hardware and in how efficiently we drive it. That work is ours, and it is the reason our cost per token is lower than the market rate for the same model. We do not publish efficiency figures we have not measured, and you should be skeptical of providers who do.

Compatibility

  • OpenAI-compatible — /chat/completions works with existing SDKs. Change the base URL, keep your code.
  • Streaming — supported on all requests.
  • Usage accounting — token counts returned on both streaming and non-streaming responses.
  • Model discovery — /models publishes pricing, context length, supported features and datacenter regions.

Data handling

We do not keep your prompts

Inference runs in memory. Prompt and completion content is not written to persistent storage, is not logged, and is never used to train or fine-tune any model.

  • Prompt content stored — no
  • Completion content stored — no
  • Used for training — no
  • Retained — aggregate token counts for billing, and operational metadata (timestamp, status code, latency) for a rolling [[RETENTION_DAYS]]-day window
