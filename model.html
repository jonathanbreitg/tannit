Integration

Calling the endpoint

The API follows the OpenAI chat completions schema. Any client that speaks it will work once the base URL is changed.

# Python — openai SDK
from openai import OpenAI

client = OpenAI(
    base_url="[[API_BASE_URL]]",
    api_key="$TANNIT_API_KEY",
)

resp = client.chat.completions.create(
    model="tannit/qwen3.8-27b",
    messages=[{"role": "user", "content": "Summarise this repo."}],
    stream=True,
)

Discovery

A /models endpoint returns the served model list with pricing, context length, maximum output tokens, supported features and datacenter regions.
